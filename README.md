# 조선 518
React + TypeScript + Vite로 만든 서버 없는 역사 학습 PWA. 운영에 유료 API나 계정이 필요하지 않습니다.

## 실행
Node.js 22.12 이상(22 LTS 또는 24 LTS)을 사용합니다.
```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```
결과물은 `dist/`입니다. `dist/index.html`을 직접 열기보다 HTTP 서버로 서비스하세요.

## 구현 범위
- 27대 왕 전체 재위 연표, 왕→사건 역사 마인드맵, 학습용 시대 필터, 왕/연도/인물/사건 검색
- 27명 모두의 왕위 계승 해설: 혈연관계와 직전 왕, 계승 방식, 전후 사건 연표, 관련 인물, 결과, 질문별 상세 답변과 근거 링크
- 37개 이야기: 27명 계승 사건과 태조~세종 주요 사건, 정조 즉위·규장각·정유역변. 한자 용어와 풀이, 배경, 전개, 결과, 비유, 일화, 출처, 사건 연결
- 5개 퀴즈와 오답 복습, 책갈피, 읽은 기록, localStorage 저장 및 복구
- 반응형 다크/라이트 UI, 키보드와 Escape, 대화상자 포커스 제한
- PWA manifest와 Workbox 오프라인 앱 캐시. 첫 온라인 방문 후 앱 파일을 저장합니다. 외부 출처 페이지는 오프라인에서 접근할 수 없습니다. 앱은 외부 웹 폰트 없이 시스템 글꼴을 사용합니다.
- 모든 왕에게 계승 해설을 제공합니다. 재위 중의 모든 사건을 망라하지는 않으며 퀴즈는 현재 태조~세종 5문항입니다.

## 구조와 확장
- `src/data/history.ts`: King / HistoryEvent 타입, 왕 27명, 시대, 사건, 퀴즈
- `src/data/easy-history.ts`: 27명 첫 읽기 안내(누구/이유/그 뒤)와 쉬운 용어 풀이
- `src/EasyGuide.tsx`: 세 단계 안내와 클릭해서 펼치는 용어 설명
- `src/data/succession.ts`: 27대 왕 계승 해설과 출처. 공통 구조의 연표와 질문/답변, 정조의 추가 설명
- `src/SuccessionStory.tsx`: 계승 방식·관계·연표·궁금증 펼침
- `src/main.tsx`: 화면과 상태/저장 동작
- `src/MindMap.tsx`: 왕과 사건을 연결하는 반응형 역사 지도
- `e2e/learning.spec.ts`: 데스크톱·모바일 Chromium 클릭/화면/PWA 오프라인 테스트
- `src/style.css`: 테마와 모바일/데스크톱 스타일
- `src/App.test.tsx`: 왕/사건 펼침, 검색, 복습, 저장 복원, 데이터 연결 무결성 테스트

재위 중 사건을 추가할 때 history.ts에 고유 사건 id, king 번호, 검토된 출처, 글자 풀이와 related를 추가하세요. 상세 제공 여부는 events의 왕 번호로 자동 판정합니다. 27명 계승 사건은 succession.ts에서 생성하므로 계승 내용은 그 파일을 고치세요. 별도 사건은 history.ts의 coreEvents에 추가합니다. 퀴즈는 현재 조선 전기 5문항입니다. 다른 시대 확장 시 era 필드를 추가해 필터링하세요.

## 역사 편집 원칙과 검증 한계
사건 이름의 한자 표기는 원문 사료 문장과 구분합니다. 현재 본문은 사료 전문 번역을 제공하지 않습니다. 글자별 대표 훈음과 문맥 해석을 분리하고 고유명사와 간지를 직역하지 않습니다. 비유는 학습용이며, 사실/설화는 라벨을 붙입니다. 전문 역사학자의 감수는 아직 받지 않은 1차 학습 콘텐츠입니다. 공개 교육 서비스로 확장하기 전 사건별 사료와 한자 사전 대조 검토가 필요합니다.

참고한 자료와 개별 사건 링크는 앱에서 확인할 수 있습니다: 국사편찬위원회 우리역사넷, 한국학중앙연구원 한국민족문화대백과사전, 국립국어원 훈민정음 해설. 시대 경계는 정설을 단정하지 않는 학습용 분류입니다. 고종/순종 구간에는 1897년 이후 대한제국 시기가 포함됩니다.

## GitHub Pages 무료 배포
배포 대상: https://github.com/sh4sh-ux/history

접속 주소: https://sh4sh-ux.github.io/history/ `.github/workflows/deploy.yml`은 main 푸시 시 단위 테스트/빌드/브라우저 테스트 후 Pages에 배포합니다. 테스트 화면 캡처와 HTML 보고서는 Actions의 `browser-test-results` 아티팩트에서 내려받습니다.
1. 이 프로젝트를 public 저장소 `sh4sh-ux/history`에 올립니다.
2. 저장소 Settings → Pages → Source를 GitHub Actions로 선택합니다.
3. main에 푸시하거나 Actions에서 Deploy GitHub Pages를 실행합니다.
4. Actions의 github-pages environment URL로 접속합니다.
`base: '/history/'`를 사용해 저장소 하위 경로에서 앱 파일과 서비스 워커가 작동하도록 구성했습니다. URL은 해시/라우터를 쓰지 않아 새로고침 404가 발생하지 않습니다. HTTPS에서 PWA 설치/서비스 워커를 사용하세요.

기록은 기기와 브라우저별로 저장되며 기기 간 동기화는 없습니다. 브라우저 데이터 삭제 시 함께 삭제됩니다.

## 이번 콘텐츠 검토
왕별 한국민족문화대백과사전 항목과 국사편찬위원회 자료를 대조했습니다. 정조 대리청정은 영조실록 51년 12월 7일 기록, 즉위는 정조실록 즉위년 3월 10일 기록을 확인했습니다. 원문 날짜는 음력이며 일부 현대 자료의 양력 날짜와 혼동하지 않도록 표시합니다. 독살설·양녕의 의도적 양보 같은 이야기는 확정 사실과 구분합니다.

자동 검증은 27명 계승 해설의 실제 펼침과 37개 사건 열기를 포함하며, 역사 내용에 대한 전문가 감수를 대신하지는 않습니다.

## 쉬운 읽기
각 왕의 첫 화면은 짧은 관계 설명 → 왕이 된 이유 → 그 뒤의 변화 순으로 읽습니다. 자세한 배경은 별도로 펼치고, 낯선 말은 같은 화면에서 눌러 뜻을 확인합니다. 본문은 모바일에서도 14~15px 이상을 사용합니다.

## 한국사능력검정시험 기출 풀이
`역사 퀴즈 → 한능검 기출시험`에서 사용할 수 있습니다.
- 제47회 이후 심화·기본 50문항 형식 지원. 심화 5지선다/80분, 기본 4지선다/70분.
- 공식 자료실 링크에서 사용자가 받은 문제지 PDF를 불러와 읽고 답을 표시합니다. 공식 기출 원문이나 타사 해설을 저장소에 재배포한 문제은행은 아닙니다.
- PDF는 IndexedDB에, 답안·타이머·최근 10회 결과·오답 메모는 별도 localStorage 키에 보관합니다. 기존 학습 기록과 독립적이며 서버 업로드는 없습니다.
- 제출한 뒤 공식 정답표 PDF를 읽거나 정답 번호 50개를 직접 넣을 수 있습니다. PDF 자동 인식은 같은 줄에 `문항 번호 정답 배점`이 있는 텍스트형 표를 지원하며, 50개 번호가 모두 있고 배점 합계가 100일 때만 미리보기를 만듭니다. 스캔 이미지와 다른 표 구조는 직접 입력을 사용합니다.
- 항상 미리보기에서 회차·종류·50개 정답을 확인한 뒤 채점을 적용합니다. 배점이 없으면 정답 수만 표시하고, 배점까지 넣으면 가중 점수와 급수 기준을 표시합니다. 연습 기록이며 공식 시험 인증이 아닙니다.
- PDF는 40MB, 정답표는 10MB까지 지원합니다. 브라우저 데이터 삭제/저장 공간 제한 시 파일을 다시 불러와야 할 수 있습니다.
- `scripts/prepare-pdf.mjs`가 설치된 pdfjs-dist의 CMap·폰트·WASM을 빌드 전에 복사합니다. 큰 PDF 뷰어는 필요할 때 로드하고 앱 자산은 서비스 워커에 캐시합니다. 공식 외부 링크를 열 때에는 인터넷이 필요합니다.

공식 근거(2026-11-01 확인):
- 자료실: https://www.historyexam.go.kr/pst/list.do?bbs=dat
- 정답 보기: https://www.historyexam.go.kr/answer/list.do
- 문항·배점·급수: https://www.historyexam.go.kr/pageLink.do?link=examGuideline&netfunnel=Y
- 시간: https://www.historyexam.go.kr/pageLink.do?link=apyexmInfo&netfunnel=Y
- 개편: https://www.history.go.kr/board/boardDetail.do?itemId=000000011737&itemIndex=2&menuId=000000000944&totalCount=24

브라우저 검사는 공식 문제를 복제하지 않고 만든 테스트용 PDF로 열기·페이지 전환·정답표 인식·답안 복원·채점·오답 메모를 확인합니다. 모든 공식 PDF의 글꼴/표 구조를 검증한 것은 아닙니다.

## 강의별 실제 기출 연결
`왕조 연표 → 왕 설명`과 `사건 상세`에 관련 한능검 기출을 표시합니다. `역사 퀴즈 → 강의별 기출`에서는 읽은 사건, 왕, 전체 연결 기출, 복습할 문항으로 찾습니다.

- 현재 70·71·73·75회 심화 중 12문항의 연결 정보를 제공합니다. 모든 회차나 모든 왕을 망라하지 않습니다. 미등록 강의에는 준비 중 안내를 표시합니다.
- `src/data/past-questions.ts`에서 회차·종류·문항 번호·배점·원문 링크·대조 자료와 왕/사건 연결 이유를 관리합니다. 정종에는 태조 때의 왕자의 난을 **정종의 즉위 배경**으로 연결하며, 사건이 정종 때 일어났다고 바꾸지 않습니다.
- 원문 지문·그림·보기는 복제하지 않고 전자문제집 CBT의 해당 문항(73회는 회차 전체)으로 연결합니다. 외부 원문 페이지에는 정답도 표시될 수 있습니다. 공식 원본 문제지·정답표는 국사편찬위원회 자료실에서 확인합니다.
- 앱의 제목은 출제 주제를 설명하는 편집 제목입니다. 연결 이유·힌트·쉬운 해설은 직접 작성한 학습 안내이며 기출 지문이나 재구성 문제로 제시하지 않습니다.
- 같은 왕의 다른 주제는 왕별 목록에서 보여 주되, 읽은 이야기 목록에는 해당 사건과 명시적으로 연결한 문항만 포함합니다. 예: 훈민정음을 읽어도 북방 개척 문항을 자동으로 읽은 강의의 기출에 넣지 않습니다.
- 풀이 결과는 사용자가 ‘맞혔어요/복습할래요’로 직접 남긴 기록입니다. 자동 채점 결과와 구분하며 `joseon518-lesson-past-v1`에 독립적으로 저장합니다. 50문항 시험의 자동 채점 기능은 그대로 사용할 수 있습니다.
- `src/exam/LessonQuestions.test.tsx`와 `e2e/lessons.spec.ts`에서 강의 연결, 펼침, 출처 링크, 읽은 사건 필터, 복습 저장·복원·제거, 모바일 가로 넘침을 검사합니다. 외부 사이트 자체의 정상 운영이나 모든 원문 링크의 장기 유효성을 보장하는 검사는 아닙니다.

연결 정보를 추가할 때 원문과 정답을 대조하고 `kings`에 시대/계승 배경 관계를, `lessons`에 실제 학습 주제와 연결 이유를 명시하세요. 미확인 회차·번호를 추측해서 넣지 마세요.
